# Sổ Cân Điều – bản iPhone (chạy offline)

Mở https://sangmd2810.github.io/socandieu-app/ bằng Safari → Chia sẻ → **Thêm vào MH chính**.
Mở app từ biểu tượng 1 lần khi có mạng; sau đó dùng được khi mất mạng.

Cập nhật app: sửa `index.html`, đồng thời đổi `socandieu-v1` → `v2`… trong `sw.js` để máy nhận bản mới.
